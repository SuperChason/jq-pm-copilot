## 本仓库中的使用方式

jq-pm-copilot 吸收并重新组织了以下公开方法：

- 将候选方向、假设识别、验证排序和实验设计串成产品发现闭环。
- 从方案中筛选会改变方向、范围或验收结论的承重假设。
- 为承重假设设置失败条件、停止或转向阈值和最低成本验证。
- 对照文档意图、当前实现和验证证据，减少只看单一材料造成的误判。
- 使用单元测试和仓库一致性检查维护版本、文档与 Skill 行为。

本仓库结合企业产品经理工作进一步增加了：

- 八类风险假设及有权角色确认点。
- 产品上下文中的决定、假设、责任人和最晚确认点回写。
- PRD、原型、实现、测试四层证据与 P0 至 P3 评审衔接。
- 按钮、权限、数据范围、状态流转和异常恢复的企业后台检查重点。
- Codex、Claude Code 和 WorkBuddy 共用的验收题与能力降级规则。

本仓库保留现有 Skill 的职责边界，并以中文企业产品工作流重新设计具体协议和输出格式。上游项目名称仅用于许可与溯源说明。
